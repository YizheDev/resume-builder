# Resume Builder — 需求设计文档（v4）

日期：2026-06-09

---

## 一、产品定位

AI 驱动的简历生成器。用户通过对话式交互，AI 引导完成 7 大模块的信息收集，自动生成完整简历。支持跳过/推荐填充、照片上传、手动编辑，确认无误后一键导出 PDF。

## 二、完整流程

```
输入背景 → AI推荐岗位 → 多选勾选 → 多轮问答（7模块逐一收集）
→ AI润色生成初稿 → 编辑模式手动打磨 → 导出PDF
```

## 三、简历内容结构（7 模块）

每份 AI 生成的简历必须包含以下模块，保证至少一页 A4 纸：

### 3.1 个人信息 + 照片
- 姓名、手机、邮箱、所在地
- LinkedIn / GitHub（选填）
- 求职意向：目标岗位
- **个人照片**：支持上传 JPG/PNG，自动裁剪为证件照比例，嵌入模板固定位置

### 3.2 教育背景
- 学校、专业、学位、起止时间
- GPA（选填）
- 相关课程（AI 根据岗位筛选 3-5 门）

### 3.3 奖项荣誉
- 竞赛获奖、奖学金、荣誉称号
- AI 润色："三等奖" → "省级三等奖（前 10%）"

### 3.4 实习/工作经历
- 公司、职位、起止时间
- AI 用 STAR 法则重写描述，补充量化数据

### 3.5 项目经历
- 课程设计、个人项目、开源贡献
- AI 挖掘亮点，包装成专业描述

### 3.6 技能
- 按熟练度分级：精通 / 熟练 / 了解
- AI 根据岗位类型自动推荐必备技能

### 3.7 自我评价
- 2-3 段简洁有力的自我总结
- AI 结合用户背景和目标岗位生成

## 四、跳过 / 推荐填充机制

用户不确定某字段时，每个空字段旁提供三个选项：

| 按钮 | 行为 |
|------|------|
| ✍️ **AI 帮我写** | AI 根据已有信息自动生成，用户确认或修改 |
| 💡 **参考选项** | AI 生成 3 个不同风格版本，用户选一个微调 |
| ⏭️ **跳过** | 留空，导出时该模块不显示 |

AI 推荐触发场景：
- 自我评价写不出来 → AI 根据教育+经历+技能自动生成
- 不知道该列什么技能 → AI 根据岗位推荐必备技能清单
- 项目描述只会说名字 → AI 根据项目名和技术栈推测内容

## 五、个人照片上传

- 格式：JPG / PNG
- 自动裁剪为 1寸（25×35mm）证件照比例
- 照片在模板中的固定位置：个人信息区域的右上角，与姓名同行
- 无花哨边框，保持专业感

## 六、模板设计原则

**全部模板：简洁专业，无任何花哨装饰**

| 禁止 | 允许 |
|------|------|
| 彩色渐变背景 | 纯白底色 |
| 装饰性图标 | 简洁线条分隔 |
| 多种颜色混搭 | 黑 + 单色强调（深蓝/深灰） |
| 进度条/图表/星标 | 纯文字列表 |
| 艺术字体 | 系统字体（微软雅黑） |

5 套模板仅差异于布局结构（单栏/双栏/侧边栏），配色和字体保持一致。

## 七、编辑模式

```
左侧模块导航 → 右侧表单编辑 + 实时A4预览
每个空字段：底部显示 [AI帮我写] [参考选项] [跳过]
有内容后：可手动修改 / 删除 / 重新排序
底部：[继续AI对话] [保存] [导出PDF]
```

## 八、AI 润色标准

| 用户说 | AI 优化成 |
|--------|----------|
| "写了几个接口" | "负责 XX 模块后端 API 设计与开发，实现 CRUD 及复杂查询接口共 12 个" |
| "参加了竞赛" | "代表学校参加 2024 年全国大学生 XX 竞赛，获得省级二等奖（前 5%）" |
| "会用 Python" | "熟练使用 Python，掌握 Flask/Django Web 框架、Pandas 数据处理" |
| "数据库" | "熟练掌握 MySQL 数据库设计与性能优化，熟悉索引策略、SQL 调优" |
| "不知道写什么" | AI 根据已有信息自动生成推荐内容 |

## 九、页面路由

```
/                    首页 → 输入背景信息
/recommend           岗位推荐 → 勾选岗位 → 开始生成
/chat/:id            对话页 → AI 问答收集信息
/edit/:id            编辑页 → 手动修改 + 预览 + 导出
```

## 十、数据库

```sql
CREATE TABLE resumes (
    id           INT AUTO_INCREMENT PRIMARY KEY,
    title        VARCHAR(100) NOT NULL DEFAULT '未命名简历',
    role         VARCHAR(100) NOT NULL,
    template     VARCHAR(50)  DEFAULT 'classic',
    data         JSON NOT NULL,
    photo_url    VARCHAR(500),            -- 照片路径
    chat_history JSON,
    status       VARCHAR(20) DEFAULT 'chatting',
    created_at   DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at   DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
```

## 十一、MVP 范围

**必做：**
- ✅ AI 背景分析 + 岗位推荐
- ✅ 多岗位并行生成
- ✅ 7 模块完整问答
- ✅ 跳过/推荐填充/AI帮我写
- ✅ 照片上传 + 模板嵌入
- ✅ 简洁专业模板（无花哨）
- ✅ 编辑模式 + 实时预览

- ❌ 简历诊断/评分
