# Resume Builder — 需求设计文档（v3）

日期：2026-06-09

---

## 一、产品定位

**AI 驱动的简历生成器。** 用户不需要知道怎么写简历，AI 通过问答引导用户，自动生成完整的专业简历。生成后支持手动修改，确认无误后一键导出 PDF。

核心原则：AI 负责从 0→1 生成初稿，用户负责从 1→100 精细打磨。

## 二、完整流程

```
用户进入 → 输入背景（自我介绍/学校/专业/经历/技能）
         ↓
       AI 分析 → 推荐岗位（可多选）
         ↓
       用户勾选多个岗位 → 同时生成多份简历
         ↓
       AI 多轮问答（逐个简历对话，收集信息）
         ↓
       AI 生成完整简历初稿（至少一页纸）
         ↓
       进入编辑模式 → 用户手动修改任意字段
         ↓
       用户确认满意 → 导出 PDF
```

## 三、简历内容结构（完整一页）

每份 AI 生成的简历必须包含以下模块，确保能拼凑出完整一页纸：

### 3.1 个人信息
- 姓名、手机、邮箱、所在地
- LinkedIn / GitHub（选填）
- 求职意向：目标岗位、城市、薪资（选填）

### 3.2 教育背景
- 学校、专业、学位、起止时间
- GPA（选填，AI 判断是否值得写）
- 相关课程（AI 根据岗位筛选 3-5 门最相关的）

### 3.3 奖项荣誉
- 竞赛获奖、奖学金、荣誉称号
- AI 自动润色："获得了三等奖" → "XX 竞赛省级三等奖（前 10%）"

### 3.4 实习/工作经历
- 公司、职位、起止时间
- 工作描述：AI 用 STAR 法则重写
  - 用户说："我在 XX 公司实习，写了一些接口"
  - AI 生成："负责 XX 电商平台订单模块后端开发，基于 Spring Boot 设计 RESTful API，日均处理 1000+ 订单请求，接口响应时间优化至 200ms 以内"

### 3.5 项目经历
- 课程设计、个人项目、开源贡献
- AI 挖掘项目亮点，包装成专业描述
  - 用户说："我做了一个简单的电商网站"
  - AI 生成："基于 Spring Boot + Vue 的 B2C 电商平台，实现用户认证、商品管理、购物车、订单系统等核心功能模块，使用 Redis 缓存提升查询性能 60%"

### 3.6 技术栈 / 技能
- 按熟练度分级：精通 / 熟练 / 了解
- AI 根据岗位 JD 自动排列优先级
- 区分：编程语言、框架、工具、数据库

### 3.7 自我评价
- 2-3 段简洁有力的自我总结
- AI 结合用户背景和目标岗位生成
- 避免空话："有良好的团队协作能力" → "在 XX 项目中担任组长，协调 5 人团队在 2 周内完成项目交付"

## 四、AI 问答交互设计

### 4.1 引导式追问

```
AI 对每个模块逐一提问：

📋 个人信息 → 自动填充（用户最初已提供）
🎓 教育背景 → AI 追问：有奖学金或竞赛获奖吗？
💼 实习经历 → AI 追问：具体做了什么？团队规模多大？有什么成果？
📦 项目经历 → AI 追问：这个项目解决了什么问题？你负责哪部分？
🛠️ 技能 → AI 自动提取（从对话中识别技术关键词）
📝 自我评价 → AI 追问：你觉得自己最大的优势是什么？
```

### 4.2 AI 润色标准

| 用户说 | AI 优化成 |
|--------|----------|
| "写了几个接口" | "负责 XX 模块后端 API 设计与开发，实现 CRUD 及复杂查询接口共 12 个，通过 Swagger 生成接口文档便于前端联调" |
| "参加了竞赛" | "代表学校参加 2024 年全国大学生 XX 竞赛，获得省级二等奖（前 5%），负责算法设计与代码实现" |
| "会用 Python" | "熟练使用 Python，掌握 Flask/Django Web 框架、Pandas 数据处理、Selenium 自动化测试" |
| "数据库" | "熟练掌握 MySQL 数据库设计与性能优化，熟悉索引策略、SQL 调优、分库分表方案" |

### 4.3 充实策略

AI 确保内容能填满一页纸：
- 每个经历至少 2-3 条要点
- 每条要点至少 1 行动物
- 技能至少列 8-12 项
- 自我评价至少 2 段，每段 2-3 行
- 如果用户经历少，AI 从课程设计、社团、志愿服务中挖掘

## 五、编辑模式

生成完初稿后，进入编辑模式：

```
┌─────────────────────────────────────────────┐
│  编辑模式（替换纯对话界面）                    │
│                                               │
│  左侧：模块导航                                │
│    📋 个人信息                                 │
│    🎓 教育背景                                 │
│    🏆 奖项荣誉                                 │
│    💼 实习经历                                 │
│    📦 项目经历                                 │
│    🛠️ 技能                                     │
│    📝 自我评价                                 │
│                                               │
│  右侧：表单编辑 + 实时预览                      │
│    ┌─ 表单 ────────┐ ┌─ A4 预览 ──────────┐  │
│    │ 可增删改全部字段 │ │ 实时渲染            │  │
│    │ 支持手动打字    │ │ 所见即所得          │  │
│    └───────────────┘ └────────────────────┘  │
│                                               │
│  底部：                                       │
│    [继续AI对话] [保存] [导出PDF]              │
└─────────────────────────────────────────────┘
```

- 所有字段可手动修改
- 支持增加/删除条目
- 右侧 A4 纸实时预览
- 不满意可以切回对话模式继续让 AI 改

## 六、页面路由

```
/                    首页 → 输入背景信息
/recommend           岗位推荐 → 勾选岗位 → 开始生成
/chat/:id            对话页 → AI 问答收集信息
/edit/:id            编辑页 → 手动修改 + 预览 + 导出
```

## 七、AI 模块

| 模块 | 输入 | 输出 | LLM |
|------|------|------|-----|
| 岗位分析 | 用户背景文本 | 推荐岗位列表 + 匹配度 | DeepSeek |
| 问答交互 | 对话历史 + 目标岗位 | AI 追问 + 更新字段 | DeepSeek |
| 简历生成 | 收集到的所有信息 | 完整 JSON 简历 | DeepSeek |
| 内容润色 | 原始描述 + 目标岗位 | STAR 法则专业描述 | DeepSeek |

## 八、数据库

```sql
CREATE TABLE resumes (
    id           INT AUTO_INCREMENT PRIMARY KEY,
    title        VARCHAR(100) NOT NULL DEFAULT '未命名简历',
    role         VARCHAR(100) NOT NULL,
    template     VARCHAR(50)  DEFAULT 'classic',
    data         JSON NOT NULL,          -- 完整简历内容
    chat_history JSON,                   -- 对话记录
    status       VARCHAR(20) DEFAULT 'chatting',  -- chatting/editing/done
    created_at   DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at   DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
```

data JSON 完整结构：
```json
{
  "personal": { "name":"", "phone":"", "email":"", "city":"", "linkedin":"", "github":"", "jobTitle":"" },
  "education": [{"school":"","major":"","degree":"","start":"","end":"","gpa":"","courses":""}],
  "awards": [{"name":"","level":"","date":"","description":""}],
  "experience": [{"company":"","title":"","start":"","end":"","highlights":["","",""]}],
  "projects": [{"name":"","role":"","description":"","techStack":"","highlights":["","",""]}],
  "skills": [{"name":"","level":"精通/熟练/了解"}],
  "summary": ""
}
```

## 九、MVP 范围

**必做：**
- ✅ 背景输入 → AI 推荐岗位
- ✅ 多岗位勾选 → 并行生成
- ✅ 7 模块完整问答流程
- ✅ AI 润色（STAR 法则 + 量化数据）
- ✅ 内容充实策略（保证一页纸）
- ✅ 编辑模式（手动修改所有字段）
- ✅ 实时 A4 预览
- ✅ 一键导出 PDF

**不做：**
- ❌ 登录/用户系统
- ❌ 简历诊断/评分
- ❌ 校招、面经等生态
