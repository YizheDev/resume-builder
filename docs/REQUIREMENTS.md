# Resume Builder — 需求设计文档

日期：2026-06-09
版本：v1.0

---

## 一、产品定位

在线简历编辑与 PDF 导出工具。类似超级简历（WonderCV）的精简版，聚焦核心的「模板 → 编辑 → 预览 → 导出」流程。

**与超级简历的区别：**

| | 超级简历 | 我们 MVP |
|------|---------|---------|
| 模板数量 | 5000+ | 3-5 套 |
| AI 功能 | 完整 AI 体系 | 无（二期加） |
| 平台 | Web/iOS/Android/鸿蒙/小程序 | Web 端 |
| 登录 | 微信扫码 | 可选（二期加） |
| 导出 | PDF/Word/图片 | PDF |
| 目标用户 | 全量求职者 | 个人使用 + 朋友 |

## 二、用户角色

- **编辑者**：创建、编辑、导出自己的简历（无需登录）
- **管理员**：查看已创建的简历列表（二期）

## 三、核心功能（MVP）

### 3.1 模板选择

```
首页 → 展示 3-5 套模板卡片
  ├── 实习生/校招模板
  ├── 社招通用模板
  ├── 技术岗模板
  ├── 简约模板
  └── 英文模板
点击 → 进入编辑器
```

### 3.2 简历编辑器

```
┌─────────────────────────────────────────────┐
│  左侧：表单编辑区                              │
│                                               │
│  📋 个人信息                                   │
│     姓名、电话、邮箱、地址、LinkedIn/GitHub     │
│                                               │
│  🎓 教育背景                                   │
│     [+ 添加] 学校、专业、学位、时间             │
│                                               │
│  💼 工作经历                                   │
│     [+ 添加] 公司、职位、时间、描述             │
│                                               │
│  🛠️ 技能                                       │
│     [+ 添加] 技能名称、熟练度                   │
│                                               │
│  📝 自我评价                                   │
│     文本输入，支持 Markdown                    │
│                                               │
├─────────────────────────────────────────────┤

│  根据左侧表单实时渲染                          │
```

### 3.3 PDF 导出

- 浏览器端生成（html2pdf.js）
- 保持 A4 排版
- 一键下载

### 3.4 简历管理

- 创建新简历
- 保存到服务器（MySQL）
- 载入已有简历继续编辑
- 删除

## 四、模板设计

### 模板 1：经典通用（应届生/实习生）

- 深蓝色标题栏 + 白色内容区
- 两栏布局：左侧个人信息 + 技能，右侧经历
- 适合：无工作经验或 1-3 年

### 模板 2：专业简约（社招）

- 单栏布局
- 顶部姓名 + 联系方式
- 模块：个人总结 → 工作经历 → 教育 → 技能
- 适合：3 年以上工作经验

### 模板 3：技术岗

- 侧边栏深色背景
- 左侧：技能树、GitHub 项目
- 右侧：工作经历、教育
- 适合：程序员 / 工程师

### 模板 4：现代极简

- 全白背景，细线分隔
- 线条图标
- 大号姓名 + 小号联系方式
- 适合：设计师 / 创意岗位

### 模板 5：英文简历

- 英文排版
- 美式简历格式
- 适合：外企 / 留学申请

## 五、非功能性需求

| 维度 | 要求 |
|------|------|
| 性能 | 页面加载 < 2s，PDF 生成 < 3s |
| 内存 | Go 服务 < 50MB |
| 兼容 | Chrome/Firefox/Safari 最新版 |
| 响应式 | 编辑器适配 1280px+ 屏幕 |
| 数据 | MySQL 存储，单表设计 |

## 六、页面结构

```
/                    首页（模板选择）
/editor?id=xxx       编辑器（新建/编辑）
/editor?id=new       新建简历
/preview?id=xxx      预览页（独立页面，打印优化）
```

## 七、数据模型

```sql
-- 简历主表
CREATE TABLE resumes (
    id         INT AUTO_INCREMENT PRIMARY KEY,
    title      VARCHAR(100) NOT NULL DEFAULT '未命名简历',
    template   VARCHAR(50)  NOT NULL DEFAULT 'classic',
    data       JSON         NOT NULL,  -- 简历内容（JSON格式）
    created_at DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
```

JSON 数据结构：

```json
{
  "personal": {
    "name": "", "phone": "", "email": "",
    "address": "", "linkedin": "", "github": ""
  },
  "education": [
    { "school": "", "major": "", "degree": "", "start": "", "end": "" }
  ],
  "experience": [
    { "company": "", "title": "", "start": "", "end": "", "description": "" }
  ],
  "skills": [
    { "name": "", "level": "" }
  ],
  "summary": ""
}
```
