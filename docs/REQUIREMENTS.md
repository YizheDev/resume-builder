# Resume Builder — 需求设计文档（v6 最终版）

日期：2026-06-09

---

## 一、产品定位

AI 驱动的简历生成器。用户不需要知道怎么写简历，AI 通过选择式交互引导用户，自动生成多份专业简历。支持零经验兜底、JD 靶向优化、版本管理、中英双语。

**核心原则：AI 负责从 0→1 生成初稿，用户负责从 1→100 精细打磨。**

## 二、完整流程

```
首页 → 输入背景 → AI 推荐岗位（多选）
  ↓
逐模块选择式交互（7 模块）
  ├── 有经验 → AI 列出高质量选项 → 勾选 + 自定义
  ├── 零经验 → AI 挖掘课程/社团/竞赛素材 → 生成推荐内容
  └── 每步可跳过 / AI帮写 / 参考选项
  ↓
粘贴 JD（可选）→ AI 分析关键词 → 调整简历侧重点
  ↓
AI 生成完整初稿 → AI 审查优化 → ATS 评分
  ↓
编辑模式手动打磨 → 版本快照 → 预览 → 导出 PDF
  ↓
分享链接 → 他人反馈 → 继续优化
```

## 三、核心功能

### 3.1 智能岗位推荐

用户输入背景（一句话即可），AI 推荐岗位列表：

```
我是 XX 大学 计算机科学专业 大四学生
会 Python 和 Java，做过一个电商课程设计

→ AI 推荐：
    ☑ Java 后端开发  92%
    ☑ Python 后端开发 88%
    ☐ 前端开发        65%
    ☐ 测试开发        58%
    ☐ 数据分析        45%
```

### 3.2 选择式交互（7 模块）

每个模块 AI 列出高质量选项，用户勾选 + 自定义输入：

| 模块 | AI 行为 |
|------|--------|
| 📋 个人信息 | 自动填充 + 照片上传 |
| 🎓 教育背景 | 推荐相关课程 |
| 🏆 奖项荣誉 | 推荐可能获得的荣誉 |
| 💼 实习经历 | 列出该岗位常见工作内容（10+ 选项） |
| 📦 项目经历 | 列出项目类型 + AI 根据技能反推虚拟项目 |
| 🛠️ 技能 | 必修 / 加分 / 了解 三级分类，参考 Lightcast 标准化 |
| 📝 自我评价 | AI 生成 3 个版本供选择 |

每个模块底部三个按钮：`✍️ AI帮我写` `💡 参考选项` `⏭️ 跳过`

### 3.3 零经验兜底模式

当用户没有任何实习/项目经历时，AI 自动进入「从零挖掘」模式：

```
AI：看起来你还没有实习经历。我帮你从这些地方挖掘素材：

📚 课程设计 → 包装成项目
   "Web开发课程大作业" → "独立完成全栈电商网站，Vue + Spring Boot，
   实现 12 个功能模块，通过 JWT + Redis 实现认证与缓存优化"

👥 社团活动 → 提取可迁移能力
   "在学生会干过" → "担任 XX 部长，策划并执行 3 场 500 人校级活动，
   管理 2 万元预算，锻炼了项目管理和团队协调能力"

🔬 课程实验 → 体现技术深度
   "操作系统实验" → "基于 C 语言实现多线程调度算法，深入理解进程管理、
   内存分配、文件系统等操作系统核心概念"

💡 推荐可立即开始的项目（一周可完成）
   帮你生成 3 个项目想法 + 技术栈 + 简历描述，你选一个去执行
```

### 3.4 JD 靶向优化

用户粘贴职位描述，AI 自动：

```
粘贴 JD → AI 分析:
  提取关键词: [Spring Cloud] [分布式系统] [消息队列] [团队协作]
  ↓
  调整简历:
  - 技能排序：Spring Cloud 提升到第一位
  - 经历描述：嵌入"分布式系统"关键词
  - 项目描述：强调"团队协作"和"跨部门沟通"
  - 自我评价：增加"熟悉分布式架构设计"
  ↓
  ATS 评分: 65 → 92 (提升 27 分)
```

### 3.5 模块级重新生成

用户对某个模块不满意，可单独重新生成，不影响其他已确认内容：

```
[模块] 自我评价 — 当前版本 A (技术深度向)
[🔄 重新生成] [📋 查看其他版本] [✏️ 手动修改] [🗑️ 删除]
```

### 3.6 版本管理

每次生成/编辑自动创建快照：
- 版本列表：`v1 初始生成` `v2 JD优化后` `v3 手动修改过`
- 点击任意版本预览
- 对比两个版本差异
- 回退到任意历史版本

### 3.7 分享与反馈

```
生成简历 → [🔗 生成分享链接]
→ 临时链接（24h 有效，无需登录）
→ 朋友/导师查看 + 添加评论
→ 用户收到反馈 → 决定是否采纳 → 修改
```

### 3.8 快速预览模式

用户首次访问时，可点击「看一个示例」：
- 30 秒自动演示完整流程（预设数据）
- 展示最终简历效果
- 降低首次使用心理门槛

### 3.9 进度可视化

```
┌──────────────────────────────────────────┐
│ ● 岗位选择  ● 教育背景  ○ 实习经历         │
│ ○ 项目经历  ○ 技能  ○ 奖项  ○ 自我评价    │
│ ═══════════════════ 30%                  │
│ ⏱ 预计还需 5 分钟                         │
└──────────────────────────────────────────┘
```

### 3.10 中英双语简历

中文版生成后，一键翻译为英文版：
- 保持排版一致
- 英文版自动调整（去掉照片、调整信息位置）
- AI 确保英文表达地道（非机翻）

### 3.11 照片智能处理

- 上传照片自动检测：模糊 / 背光 / 非正面 → 提示重新上传
- 自动裁剪为标准证件照比例（1 寸 / 2 寸）
- 可选：AI 抠图换背景色（蓝底 / 白底 / 红底）
- 模板中固定位置嵌入（个人信息区右上角）

## 四、AI 润色标准

| 用户说 | AI 优化成 |
|--------|----------|
| "写了几个接口" | "负责 XX 模块后端 API 设计与开发，基于 Spring Boot 实现 12 个 RESTful 接口，通过 Swagger 生成文档，Postman 完成接口测试" |
| "参加了竞赛" | "代表学校参加 2024 年全国大学生 XX 竞赛，获得省级二等奖（前 5%），负责算法设计与代码实现" |
| "会用 Python" | "熟练使用 Python，掌握 Flask/Django Web 框架，具备 Pandas 数据处理、Selenium 自动化测试能力" |
| "数据库" | "熟练掌握 MySQL 数据库设计与性能优化，熟悉索引策略、慢查询分析、SQL 调优" |
| "不知道写什么" | AI 从课程/社团/竞赛中挖掘素材，生成可选列表 |

## 五、模板设计原则

- 纯白底色，无花哨装饰
- 黑色 + 单色强调（深蓝 / 深灰）
- 照片固定位置：个人信息区右上角
- 5 套模板仅差异于布局结构

## 六、页面路由

```
/                    首页 → 输入背景 + 快速预览入口
/recommend           岗位推荐 → 多选勾选
/chat/:id            选择式交互 → 逐模块收集 + JD 优化
/edit/:id            编辑页 → 手动修改 + 版本管理 + 预览
/preview/:id         独立预览页
/share/:token        分享页（无需登录）
```

## 七、数据库

```sql
CREATE TABLE resumes (
    id           INT AUTO_INCREMENT PRIMARY KEY,
    title        VARCHAR(100) NOT NULL DEFAULT '未命名简历',
    role         VARCHAR(100) NOT NULL,
    template     VARCHAR(50)  DEFAULT 'classic',
    data         JSON NOT NULL,
    selections   JSON,                   -- 用户选择记录
    versions     JSON,                   -- [{v:1, data:{}, created_at:...}]
    photo_url    VARCHAR(500),
    chat_history JSON,
    share_token  VARCHAR(100),           -- 分享临时 token
    share_expires DATETIME,
    status       VARCHAR(20) DEFAULT 'chatting',
    created_at   DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at   DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);

CREATE TABLE resume_feedbacks (
    id         INT AUTO_INCREMENT PRIMARY KEY,
    resume_id  INT NOT NULL,
    comment    TEXT,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (resume_id) REFERENCES resumes(id)
);
```
